
# Indonesian Stock Market Intelligence

## 1. Project Overview
Menganalisis performa historis dan risiko saham di Bursa Efek
Indonesia menggunakan Python, Pandas, pengumpulan data publik,
dan Power BI.

## 2. Business Problem
Data harga saham mentah sulit dibandingkan secara langsung.
Project ini bertujuan mengolah data menjadi informasi yang
membantu memahami performa dan risiko historis saham.

## 3. Business Questions
1. Saham mana yang memiliki return kumulatif tertinggi?
2. Saham mana yang memiliki volatilitas tertinggi?
3. Saham mana yang mengalami maximum drawdown terbesar?
4. Bagaimana perbandingan performa antar-sektor?
5. Bagaimana hubungan antara return dan risiko historis?

## 4. Project Scope
- Market: Bursa Efek Indonesia
- Initial sample: 5 stocks
- Target period: 3 years, subject to data availability
- Frequency: Daily
- Tools: Python, Pandas, web data collection, Power BI

## 5. Analysis Metrics
- Daily Return
- Cumulative Return
- Annualized Volatility
- Maximum Drawdown

## 6. Expected Deliverables
- Raw and cleaned datasets
- Python data collection and cleaning scripts
- Exploratory data analysis notebook
- Power BI dashboard
- At least 3 evidence-based findings
- GitHub documentation

## 7. Limitations
Historical data availability and quality depend on the data source.
Past performance does not guarantee future results.
This project is for educational and analytical purposes,
not investment advice.
